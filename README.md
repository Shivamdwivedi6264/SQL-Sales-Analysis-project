# E-commerce Sales & Customer Analytics — SQL Project

## Project Overview
This project analyzes e-commerce sales and customer data using SQL and MySQL. The goal is to extract useful business insights about sales performance, products, customers, orders, and payments.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Database Tables
The project includes the following tables:
- `customers` — Customer information
- `products` — Product details and prices
- `orders` — Order information
- `order_items` — Products and quantities in each order
- `payment` — Payment information

## SQL Concepts Used
- Database and table creation
- Data insertion using `INSERT INTO`
- Data cleaning and validation
- Filtering using `WHERE`
- Sorting using `ORDER BY`
- Aggregate functions: `SUM()`, `COUNT()`, `AVG()`
- Grouping using `GROUP BY` and `HAVING`
- Joins across multiple tables
- Date functions and monthly sales analysis
- Subqueries and Common Table Expressions (CTEs)
- Window functions *(if implemented)*

## Business Questions
1. What are the total sales?
2. What are the monthly sales trends?
3. How many orders were placed each month?
4. What is the average order value (AOV)?
5. Which are the top 5 products by revenue?
6. How much has each customer spent?
7. Which products have prices above the average price?
8. How can missing or duplicate data be identified?

## Project Workflow
1. Created the database and tables.
2. Inserted data into the tables.
3. Checked data quality and validated records.
4. Wrote SQL queries to analyze business performance.
5. Interpreted query results to identify business insights.

## Key Learnings
- Working with relational databases.
- Writing SQL queries for business analysis.
- Combining data from multiple tables.
- Analyzing sales, products, customers, and payments.
- Checking data quality before analysis.

## Conclusion
This project demonstrates practical SQL skills for e-commerce data analysis and supports data-driven business decision-making.
